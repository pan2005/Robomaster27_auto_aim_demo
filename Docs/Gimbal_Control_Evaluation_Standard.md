# 云台控制算法测试与评价标准

## 1. 文档目的

本文档用于回答一个基础问题：**怎样定义云台控制算法的好坏？**

它将作为以下工作的共同评价基准：

- 电机与云台系统辨识；
- PID、前馈与摩擦补偿设计；
- 大模型自动调参；
- 视觉自瞄与目标预测；
- 不同算法、参数和固件版本之间的公平比较。

好的控制算法不是在某一次阶跃中“曲线好看”，而是能够在安全约束内，以较小且平滑的控制量，快速、准确、稳定地跟踪目标，并在负载、方向、姿态和运动频率变化后仍保持性能。

---

## 2. 总体原则

### 2.1 评价是多目标问题

云台性能至少包含：

1. 跟踪精度；
2. 响应速度；
3. 抗扰能力；
4. 平滑性；
5. 鲁棒性；
6. 电流、温升与机械冲击；
7. 自瞄任务中的最终命中效果。

这些目标通常相互冲突。提高增益可能缩短响应时间，但也可能增加超调、噪声、电流和机械振动。因此，不应使用单一指标决定算法优劣。

### 2.2 安全约束优先于性能评分

评价采用两级结构：

1. **安全门槛**：违反任一硬约束，实验立即终止，本组参数判定不合格；
2. **性能评分**：仅对通过安全门槛的实验计算综合得分。

这样可以防止自动调参通过极端增益或持续饱和获得表面上的低误差。

### 2.3 所有比较必须可复现

不同算法必须使用相同的：

- 初始姿态和机械安装状态；
- 目标轨迹；
- 负载与供电电压；
- 采样率和数据处理流程；
- 电流、速度和角度限制；
- 评价区间和评分代码。

每次实验都必须保存固件版本、参数、原始数据、终止原因和环境信息。

---

## 3. 分层评价体系

### 3.1 电机速度环

输入为目标转速，输出为电机反馈转速。主要评价：

- 上升时间和调节时间；
- 超调量；
- 稳态速度误差；
- 速度跟踪 RMSE；
- 电流峰值、RMS与饱和时间；
- 高频振荡和控制量变化率；
- 正反方向响应的一致性。

该层主要用于研究电机模型、速度PID、速度/加速度前馈、静摩擦和死区补偿。

### 3.2 云台姿态环

输入为目标 Yaw/Pitch 角度，输出以IMU姿态为主，电机编码器作为安全限位和结构状态参考。主要评价：

- 角度跟踪误差；
- 快速转向时间；
- 超调和残余振荡；
- 匀速轨迹下的滞后角；
- 外部扰动后的最大偏移与恢复时间；
- 编码器角度与IMU角度之间的差异；
- 不同方向、幅值和Pitch姿态下的性能一致性。

### 3.3 自瞄任务层

输入为视觉系统产生的目标轨迹，输出为云台实际指向。最终评价：

- 目标角误差或图像平面像素误差；
- 目标运动时的相位滞后；
- 进入允许开火误差带所需时间；
- 保持在允许误差带内的时间比例；
- 开火时刻的预测误差；
- 对通信延迟、视觉噪声和目标突变的鲁棒性；
- 最终命中率。

底层控制器阶跃响应良好，不代表自瞄性能一定良好。最终目标必须回到真实目标轨迹与开火窗口。

---

## 4. 安全门槛

以下任一条件发生时，应在下一控制周期将电流指令归零、记录原因并终止实验：

- 超过软件或机械角度限位；
- 电机离线、CAN Bus-Off或反馈超时；
- IMU失效或姿态数据无效；
- 实际转速超过实验上限；
- 电流指令超过硬限制；
- 电流持续饱和超过允许时间；
- 出现持续振荡、自激运动或明显失控趋势；
- 电机或驱动温度超过限制；
- 收到主机停止命令；
- 实验超时或数据链路异常。

每项保护都应单独测试，不能只通过代码审查推断其有效。

当前Yaw辨识固件的保守硬限制为：

| 项目 | 限制 |
|---|---:|
| 电流指令 | ±2000 |
| 电机转速 | ±60 rpm |
| 相对启动角度 | ±45° |
| 单次实验时间 | ≤60 s |

## 5. 标准测试矩阵

### 5.1 静止测试

目标角保持不变至少30秒，记录：

- 角度均值、标准差和峰峰值；
- 电机转速均值和标准差；
- 电流RMS及峰值；
- 高频抖动；
- IMU漂移和温度变化。

目的：检查噪声放大、积分漂移、自激振荡和不必要能耗。

### 5.2 小角度阶跃

建议轨迹：`0° → +3° → 0° → -3° → 0°`。

目的：测试静摩擦、死区、小范围精度、调节时间和停止抖动。

### 5.3 大角度阶跃

建议轨迹：`0° → +30° → 0° → -30° → 0°`。

目的：测试快速运动、饱和、超调、制动能力和大范围非线性。

### 5.4 匀速斜坡

建议至少测试 `10°/s、30°/s、60°/s`，并同时执行正反方向。

目的：评价持续跟踪误差和相位滞后。该测试对验证速度前馈最重要：纯反馈通常会产生稳定滞后，正确的速度前馈应明显降低该误差。

### 5.5 正弦与扫频测试

在安全角度范围内使用不同频率的正弦目标或受限Chirp，记录幅值比和相位差。

目的：测量闭环带宽、高频衰减和机械共振，避免控制器在单一阶跃上过拟合。

### 5.6 可重复扰动测试

保持目标角不变，施加幅值和持续时间可重复的外部扰动。

目的：评价最大偏移角、恢复时间和扰动误差积分。正式自动测试可使用另一台电机施加标准力矩。

### 5.7 真实自瞄轨迹回放

保存典型目标运动轨迹并离线回放，包括：

- 匀速横移；
- 变速和突然变向；
- 短时遮挡后重现；
- 目标切换；
- 视觉数据抖动、丢帧和延迟变化。

目的：评价控制器在真实上层输入中的最终表现，而不是只评价理想指令。

## 6. 核心评价指标

定义目标角与实际角的误差：

\[
e(t)=\theta_{ref}(t)-\theta(t)
\]

### 6.1 跟踪精度

均方根误差：

\[
RMSE=\sqrt{\frac{1}{T}\int_0^T e^2(t)\,dt}
\]

最大绝对误差：

\[
E_{max}=\max |e(t)|
\]

绝对误差积分：

\[
IAE=\int_0^T |e(t)|\,dt
\]

时间加权绝对误差：

\[
ITAE=\int_0^T t|e(t)|\,dt
\]

RMSE衡量整体精度，最大误差反映最差情况，IAE兼顾误差大小与持续时间，ITAE会更强烈地惩罚长时间拖尾。

### 6.2 瞬态性能

- 上升时间：首次从规定下限到达规定上限所需时间；
- 调节时间：进入并持续保持在误差带内所需时间；
- 超调量：响应超过目标值的最大比例或最大角度；
- 残余振荡：进入目标附近后一定时间内的峰峰值与衰减率。

误差带、测量起点和保持时间必须在评分程序中固定，不能人工挑选。

### 6.3 控制代价

控制量RMS：

\[
U_{RMS}=\sqrt{\frac{1}{T}\int_0^T u^2(t)\,dt}
\]

控制量总变差：

\[
TV(u)=\sum_k |u_k-u_{k-1}|
\]

还应记录峰值电流和饱和占空比。它们用于防止算法依靠过大或剧烈变化的电流获得表面性能。

### 6.4 鲁棒性与一致性

分别计算以下工况的性能：

- 正方向和反方向；
- 小幅和大幅运动；
- 不同Pitch姿态；
- 不同供电电压、温度和负载；
- 不同目标速度与频率。

除平均性能外，必须记录最差工况：

\[
J_{worst}=\max_i J_i
\]

平均分很好但某个方向失控的控制器不能判定为优秀。

### 6.5 自瞄专用指标

- 开火窗口内角度误差RMS；
- 开火窗口内最大误差；
- 进入允许误差带的时间；
- 位于误差带内的时间比例；
- 预测提前量误差；
- 实际命中率及置信区间。

---

## 7. 自动评分方法

### 7.1 指标归一化

不同量纲不能直接相加。每项指标应除以固定参考值：

\[
J=\sum_i w_i\frac{M_i}{M_{i,ref}}
\]

其中 `M_i` 为实测指标，`M_i,ref` 为项目固定的参考尺度，`w_i` 为权重。所有参考值和权重必须纳入版本管理。

### 7.2 姿态环第一版建议权重

| 指标 | 建议权重 |
|---|---:|
| 角度RMSE | 30% |
| ITAE | 20% |
| 调节时间 | 15% |
| 超调量 | 10% |
| 电流RMS | 10% |
| 控制量总变差 | 10% |
| 静止抖动 | 5% |

这些权重是第一版研究起点，不是永久标准。调整权重前应保存旧版本，避免历史实验失去可比性。

### 7.3 多工况综合分数

第一版可采用：

\[
J_{total}=0.2J_{small\ step}+0.2J_{large\ step}
+0.2J_{ramp}+0.15J_{sine}+0.15J_{disturbance}+0.1J_{static}
\]

同时对最差工况设置独立上限。综合分数越低越好，但任何安全门槛失败都直接判定为不合格。

### 7.4 自瞄阶段评分

进入自瞄阶段后，评分重心应改为任务指标：

\[
J_{aim}=0.4E_{fire,RMS}+0.2E_{max}+0.2T_{enter}
+0.1(1-P_{in\ band})+0.1U_{RMS}
\]

其中：

- `E_fire,RMS`：允许开火阶段的误差RMS；
- `T_enter`：进入允许误差带的时间；
- `P_in band`：位于误差带内的时间比例。

## 8. 前馈的评价方法

前馈的目标不是取代反馈，而是提前承担可预测的控制需求：

- 速度前馈补偿稳定运动所需控制量；
- 加速度前馈补偿惯量；
- 重力前馈补偿Pitch轴随姿态变化的重力矩；
- 摩擦补偿克服静摩擦、库仑摩擦和方向不对称。

比较前馈效果时，反馈参数应保持不变，分别执行“无前馈”和“有前馈”的相同实验。重点比较：

- 匀速斜坡跟踪误差；
- 加减速阶段的峰值误差；
- PID反馈项所需峰值和RMS；
- 总电流RMS与总变差；
- 正反方向一致性；
- 模型失配时是否仍保持稳定。

好的前馈应降低跟踪误差和反馈负担，而不是依靠更大的总电流掩盖误差。

---

## 9. 大模型自动调参约束

大模型不应直接获得无限制的在线电机控制权。推荐闭环流程：

1. 从一组经过人工验证的保守参数开始；
2. 大模型只在限定参数范围内提出下一组候选参数；
3. 固件独立执行硬安全保护；
4. 自动运行固定测试集并保存原始数据；
5. 独立评分程序计算指标，禁止模型自行解释或修改实验结果；
6. 只有满足所有约束且综合评分改善的参数才能成为新基线；
7. 每轮保留旧参数，支持立即回滚；
8. 定期在未参与调参的验证轨迹上检查过拟合。

建议保存完整优化历史，而不是只保存最终参数。历史数据可用于研究大模型的搜索策略、收敛速度和失败模式。

---

## 10. 实验数据最低要求

每次实验至少记录：

- MCU时间戳和连续样本序号；
- 目标角度、目标速度和目标加速度；
- IMU Yaw/Pitch与角速度；
- 电机编码器、累计角度和RPM；
- 最终电流指令及各控制分量：反馈、速度前馈、加速度前馈、重力与摩擦补偿；
- 电机反馈电流和温度；
- 饱和、限位、离线和其他安全标志；
- 控制器参数、模型版本和实验轨迹编号；
- USB丢帧、CRC错误和固件侧队列丢弃计数；
- 供电电压、负载配置和机械安装说明。

评分应尽量基于原始数据离线完成，避免固件内在线计算改变控制实时性。

## 11. 分阶段验收标准

### 阶段A：系统辨识平台

- 激励与采样时间准确；
- 无丢帧或丢帧可被明确检测；
- 训练集和验证集使用不同激励序列；
- 模型能在独立数据上解释主要动态；
- 所有安全保护通过实测。

### 阶段B：速度环与前馈

- 在多幅值、正反方向下稳定；
- 相比纯PID，匀速和加速跟踪误差下降；
- 电流峰值、RMS和抖动没有不可接受的增加；
- 模型失配时反馈仍能保持系统安全稳定。

### 阶段C：姿态环

- 小角度和大角度阶跃均满足要求；
- 扫频测试无危险共振；
- 扰动后能快速恢复；
- Pitch不同姿态下性能可接受；
- IMU漂移与编码器限位不会互相冲突。

### 阶段D：自动调参

- 自动实验可重复；
- 评分程序与调参模型相互独立；
- 任意候选参数都无法绕过固件保护；
- 优化结果在保留验证集上优于人工基线；
- 全过程可追踪并可回滚。

### 阶段E：自瞄

- 真实轨迹回放性能优于静态调参基线；
- 视觉延迟和控制延迟被统一考虑；
- 开火窗口误差和命中率达到任务要求；
- 对目标切换、丢帧和预测失误具有安全行为。

## 12. 每次实验检查表

### 实验前

- [ ] 云台机械安装、线缆和负载状态已记录；
- [ ] Yaw/Pitch均处于安全活动范围中部；
- [ ] 24 V供电、CAN和USB工作正常；
- [ ] 当前固件、模型和控制参数已保存；
- [ ] 电流、速度、角度和温度限制已确认；
- [ ] 急停或断电手段随时可用。

### 实验中

- [ ] 样本序号和时间戳连续；
- [ ] 没有CRC错误或未记录的丢帧；
- [ ] 电机反馈与指令方向一致；
- [ ] 没有异常噪声、撞击或持续振荡；
- [ ] 安全状态和温度处于允许范围。

### 实验后

- [ ] 电流已归零；
- [ ] 保存原始二进制数据、CSV和元数据；
- [ ] 检查终止状态和保护原因；
- [ ] 自动生成指标与图表；
- [ ] 与当前基线和最差工况比较；
- [ ] 记录结论、异常和下一轮假设。

## 13. 当前研究基线

截至当前实验：

- Yaw GM6020反馈ID为`0x206`，CAN1为1 Mbps；
- 辨识采样周期为1 ms；
- 1200幅值、20 ms切换周期的两组PRBS数据均采集10000点；
- 数据无丢帧、无CRC错误、无安全触发；
- 电流指令到Yaw转速的一阶惯性加延迟模型验证拟合率约73.8%；
- 初步模型为

\[
G(s)=\frac{0.0084}{0.0026s+1}e^{-0.0046s}
\]

- 该模型只是当前姿态、负载和激励幅值下的第一版模型，必须通过不同幅值、方向、温度和机械姿态继续验证，不能直接视为最终前馈参数。

## 14. 核心结论

控制算法的最终评价标准是：

> 在所有安全边界和实际工况下，以可接受的电流、温升和机械冲击，使云台快速、准确、平滑地跟踪目标；在自瞄阶段，则应进一步表现为更短的入窗时间、更高的误差带内占比和更高的实际命中率。

系统辨识、PID、前馈、大模型调参和视觉预测都只是实现这一目标的工具。评价标准必须先于优化算法确定，并在研究过程中保持可复现、可量化、可追踪。
