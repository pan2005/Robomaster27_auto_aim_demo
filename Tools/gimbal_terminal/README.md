# 海康图传与鼠标云台终端

该终端在 Windows 上通过海康机器人 MVS SDK 获取 `MV-CS016-10UC` 图像，并通过 STM32 USB CDC 控制云台。

## 首次准备

1. 从海康机器人官网下载并安装 **MVS Windows 版**，勾选 USB3 Vision 驱动和开发组件。
2. 在设备管理器中确认相机不再显示错误码 28，并先用 MVS 客户端验证连续取流。
3. 烧录本工程默认 Debug/Release 固件；系统辨识或速度测试固件不运行终端协议。
4. 双击 `run_terminal.bat`。首次运行会创建 `.venv` 并安装 PyQt5、pyserial；不会自动安装或修改相机驱动。

## 操作

- 左键点击画面：进入鼠标锁定和云台控制。
- 相机连接后默认关闭自动曝光和自动增益，并设置为 `8000 μs / 16.08 dB`；两项均可在右侧面板修改并持久化。连接状态会显示相机实际接受的曝光和增益值。
- 画面默认顺时针旋转 `90°`；可选择 `0° / 90° / 180° / 270°`，设置自动保存。
- 移动鼠标：累加 Pitch/Yaw 目标角度；鼠标停止后云台保持当前目标。
- 右键：准星附近有合格 Tag 时进入自动跟踪；再次右键退出，回到当前位置的手动控制。
- 自动跟踪时按住左键只表示持续开火授权；`fire` 仍仅记录和进入协议状态，不会驱动发射机构。
- Esc、窗口失焦、关闭程序：失能云台并释放鼠标。
- 相机掉线：终端继续发送零增量心跳，云台保持最后角度并自动尝试恢复画面。
- 串口掉线或超过 200 ms 没有有效控制帧：固件自动清零电机输出。

## 相机内参标定

标定流程参考 [TongjiSuperPower/sp_vision_25](https://github.com/TongjiSuperPower/sp_vision_25) 的相机内参方案，默认使用 `10×7` 对称圆点阵列和 `40 mm` 圆心距。

1. 有 A3 时使用 `calibration_board_10x7_40mm.svg`；只有 A4 时直接打印 `calibration_board_10x7_20mm_A4.png`。都要横向、100% 原始尺寸打印，关闭“适应页面”，贴在硬质平板上，打印后实测相邻圆心距离并填入终端（A4 理论值为 `20 mm`）。
2. 保持最终使用的分辨率、镜头焦距、对焦和顺时针90°方向不变。
3. 从正面、四角、四边采集15～25张；覆盖远近距离和约±30°倾角，避免连续保存几乎相同的姿态。
4. 每次点击“采集有效帧”；只有识别到完整圆点阵列的图片才会保存。
5. 点击“计算内参”。建议平均重投影误差小于 `0.5 px`，超过 `1.0 px` 应重新采集。

每次有效采样都会同步写入 `session.yaml`。终端重启后会自动恢复最近一次会话，并从已保存图片重新检测圆点；也可以点击“恢复最近会话”手动恢复，因此关闭终端不会再丢失采样计数。

结果保存在 `calibration_data/<时间>/camera_calibration.yaml`，字段与上游使用的 `camera_matrix`、`distort_coeffs` 兼容，并额外记录分辨率、旋转方向、板规格和逐图误差。内参标定只解决镜头模型；相机到云台的手眼外参将在下一阶段标定。

默认自动选择 VID/PID `0483:5740` 的 STM32 虚拟串口。灵敏度、方向、串口和帧率设置由 Qt 持久化。

## AprilTag 高动态自瞄

- 使用 `AprilTag 36h11`，黑色外框实测边长 `100 mm`；工作距离限定为 `1～4 m`。
- 可直接以100%原始比例打印 `apriltag_36h11_id0_100mm_A4.png`，关闭“适应页面”，并在使用前实测黑色外框是否为 `100 mm`。
- 第一次左键点击画面仍用于捕获鼠标。手动把准星移到目标附近后按右键，终端锁定离准星最近的 Tag；再次右键退出自动瞄准。
- 自动瞄准期间不会跳到其他 ID。Tag 短时丢失最多外推 150 ms，但丢失期间禁止 fire。
- 左键按住仅表示开火授权；只有观测新鲜、轨迹未饱和且实际跟踪误差持续30 ms小于0.6°时，协议中的 fire 才置位。
- 当前固件不会驱动发射 GPIO。弹速默认15 m/s只用于弹道联调，实弹前必须测量弹速、发射延迟和枪口外参。
- 自动瞄准日志写入 `aim_logs/aim_<时间>.csv`，包含视觉耗时、实际角度、规划角度/速度/加速度、饱和状态和开火门控原因。

终端使用旋转后的 `1080×1440` 图像进行 AprilTag 检测与 PnP。启动时自动加载最新的 `camera_calibration.yaml` 和（若存在）最新的 `camera_to_gimbal.yaml`。

## 相机—云台外参

1. 将 `10×7 / 20 mm` 圆点板完整贴在刚性平板上，并固定在世界坐标系中。
2. 保持标定板不动，改变云台 Yaw/Pitch；每次完全停稳后点击“采集静止姿态”。
   云台控制保持使能时可直接按 `F8` 采集：鼠标移动到位，松手等待停稳，再按 `F8`，不需要按 Esc。
3. 采集至少25个覆盖不同Yaw/Pitch的姿态，避免只有单一方向。
4. 点击“计算外参”，结果保存在 `extrinsic_data/<时间>/camera_to_gimbal.yaml` 并立即加载。

外参采集要求图像与姿态时间差不超过20 ms，并且约300 ms窗口内两轴角速度RMS不超过0.8°/s、单点峰值不超过1.5°/s；温度偏离零偏标定温度超过1.5℃或圆点重投影误差超过0.5 px时拒绝保存。每个NPZ同时记录IMU温度、标定温度、三轴陀螺Offset、角速度和加热超时状态。求解时使用MAD规则最多剔除约10%的明确离群点。当前流程联调临时采用“留出RMS小于0.5°且最大值小于0.8°”的开发门槛，并在YAML标记 `provisional: true`；最终动态验收前仍须达到最大误差小于0.5°。

新协议增加100 Hz姿态四元数、PC/STM32时钟同步以及绝对 `AIM_TARGET` 轨迹。鼠标 `CONTROL` 仍使用增量；自动瞄准使用相对启动零位的绝对角度、角速度和角加速度。通信超时、限位越界、失焦或Esc都会清除 fire 并失能。

## 协议测试

```powershell
python -m unittest discover -s Tools/gimbal_terminal/tests -v
```

协议定义位于 PC 端 `protocol.py` 与固件端 `Tasks/gimbal_protocol.[ch]`。线序均为小端，CRC 为 CRC-16/CCITT-FALSE（初值 `0xFFFF`，多项式 `0x1021`）。
